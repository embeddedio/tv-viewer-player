# 06 — Guide de Migration

Ce document detaille la migration des 3 widgets HTML existants vers le format SDUI JSON natif.

---

## 1. Strategie de migration

### Ordre

1. **`tableau-change`** — Le plus simple (5 colonnes, header simple)
2. **`currency-bkam-ref`** — Simple aussi (4 colonnes)
3. **`currency-ref`** — Le plus complexe (6 colonnes, double header)

### Principe de securite

- **Conserver les fichiers HTML** (`index.html`, `app.js`, `styles.css`) comme fallback
- Ajouter `ui.json` a cote — le moteur SDUI le detecte et l'utilise en priorite
- Si `ui.json` est supprime, l'app revient automatiquement au WebView
- Tester chaque widget migre avant de passer au suivant

---

## 2. Point d'integration (ZoneContent.tsx)

Fichier : `components/ZoneContent.tsx`

Le changement est minimal. Dans le bloc de fallback WebView (actuellement ligne ~134-138), ajouter le `NativeWidgetRenderer` avant :

```tsx
// AVANT (actuel)
return (
  <Animated.View style={[styles.fadeWrap, { opacity: cycleFade }]}>
    <WidgetWebView baseUrl={baseUrl} widgetType={currentItem.widgetType} widgetItem={currentItem} />
  </Animated.View>
);

// APRES (avec SDUI)
return (
  <Animated.View style={[styles.fadeWrap, { opacity: cycleFade }]}>
    <NativeWidgetRenderer
      baseUrl={baseUrl}
      widgetType={currentItem.widgetType}
      widgetItem={currentItem}
      fallback={<WidgetWebView baseUrl={baseUrl} widgetType={currentItem.widgetType} widgetItem={currentItem} />}
    />
  </Animated.View>
);
```

## 4. Migration : `tableau-change`

### Structure HTML actuelle

```
main.exchange-widget
  ├─ header.exchange-header (20vh)
  │   ├─ section.logo-panel (21% width)
  │   │   └─ img#widget-logo
  │   └─ section.title-panel
  │       ├─ h1 "Cours des Billets"
  │       └─ p#widget-date
  ├─ section.exchange-table-shell
  │   ├─ div.exchange-table-header
  │   │   └─ 5 cells: Unite | (flag) | Devises | Achat | Vente
  │   └─ div#exchange-table-body
  │       └─ rows (generated by app.js)
```

### Colonnes

| Colonne | Largeur CSS | Largeur SDUI | Donnee |
|---------|-------------|--------------|--------|
| Unite | `10vw` | `"10%"` | `$item.unit` |
| Drapeau | `8vw` | `40px` (image) | Image assets/ |
| Devises | `1fr` | `flex: 1` | `$item.label` |
| Achat | `14vw` | `"14%"` | `$item.buy` |
| Vente | `14vw` | `"14%"` | `$item.sell` |

### API

- Endpoint : `/api/widgets/tableau-change`
- Transform : `$response.rates`
- Shape d'un element : `{ code, label, unit, icon, buy, sell }`

## 7. Checklist de validation

Pour chaque widget migre, verifier :

### Donnees
- [ ] Toutes les colonnes s'affichent
- [ ] Les valeurs sont correctes (buy, sell, bkamReference, bkamTpe)
- [ ] Les valeurs manquantes affichent `-`
- [ ] Le rafraichissement toutes les 30 secondes fonctionne

### Visuel
- [ ] Les couleurs correspondent (rouge Achat, bleu Vente, vert BKAM, orange TPE)
- [ ] L'alternance pair/impair des lignes fonctionne
- [ ] Le header est visible avec le bon titre
- [ ] La date s'affiche et se met a jour

### Logo
- [ ] Le logo s'affiche quand il est configure
- [ ] Le fallback (lettre "M") s'affiche quand pas de logo

### Images
- [ ] Les drapeaux de devises s'affichent
- [ ] Les drapeaux manquants ne cassent pas l'affichage

### Responsive
- [ ] L'affichage est correct en 720p
- [ ] L'affichage est correct en 1080p
- [ ] Le texte ne deborde pas des colonnes
- [ ] Les noms longs sont tronques avec `...`

### Fallback
- [ ] Supprimer `ui.json` fait basculer sur le WebView
- [ ] Remettre `ui.json` restaure le rendu natif
